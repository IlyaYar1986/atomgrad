# Промпты для генерации инфографики

Изображения генерирует человек (ChatGPT / аналог) по текстовым промптам из плана страницы. Агент промпты пишет, картинки не делает.

## Общие правила стиля (обязательны в каждом промпте)

- Соотношение **16:9**, разрешение не меньше 1672×941.
- Светлый лавандово-белый фон; крупный жирный чёрный/тёмно-синий заголовок сверху; синий/фиолетовый подзаголовок под ним.
- Несколько скруглённых панелей с тонкой синей обводкой; заголовки секций — таблетки (pill-shape) индиго/тил цвета.
- Стеклянный светящийся 3D-мотив (куб, сеть, шестерня, щит, весы) как центральный визуальный якорь.
- Нижняя горизонтальная плашка-степпер: пронумерованные кружки (1, 2, 3, 4), каждый — иконка + жирный заголовок + короткая подпись, соединены пунктиром.
- Все подписи на изображении — **на русском**, орфографически точные, с буквой «ё».
- Никаких водяных знаков и реальных логотипов компаний — только текстовые названия сервисов и обобщённые иконки (глобус, сервер, розетка, щит).
- Названия продуктов как обычный текст на изображении — это нормально и нужно для ясности.

## Формат хранения

- Папка на страницу: `png/<имя_страницы>/`.
- Имена файлов: `01_hero_<тема>.png`, `02_<тема>.png`, … — номер совпадает с номером промпта в плане.
- В HTML путь `../png/<имя_страницы>/NN_....png` + `onerror`-заглушка с текстом «(промпт NN из плана)».

## Каркас промпта

```
16:9 dense professional Russian infographic in the style of a modern data-journalism explainer poster
(flat design with glossy 3D glass elements), light lavender-white background.

Bold black title top center: "<заголовок по-русски>"
Blue/purple subtitle beneath: "<подзаголовок по-русски>"

Central large glowing 3D glass motif: <центральный объект и что он символизирует>.

Left column, pill-shaped section header "<заголовок левой панели>": bordered panel with icon+label rows:
"<пункт 1>" (<иконка>), "<пункт 2>" (<иконка>), "<пункт 3>" (<иконка>).

Right column, pill-shaped section header "<заголовок правой панели>": bordered panel with icon+label rows: …

Bottom horizontal stepper across the full width: four connected numbered circles with dotted line between them:
"1" <иконка> — "<заголовок>" — "<подпись>";
"2" … "3" … "4" …

No watermarks, no real company logos, all text in correct Russian.
```

## Что работает лучше всего

- **Сравнение «до / после»** с пунктирной стрелкой: слева зачёркнутый красным беспорядок, справа один аккуратный результат.
- **Радиальная схема**: центральный объект и 4–6 подписанных карточек-лучей вокруг.
- **Числовой степпер снизу** — читается с проектора даже из последнего ряда.
- Один смысл на панель. Плотность даёт ощущение «флагманского постера», но каждая панель должна быть понятна за 3 секунды.
