# Стартовый кит: вебинар «ИИ-агенты для бизнеса»

Заготовка нового проекта. Здесь собрано всё, что нужно агенту, чтобы делать страницы в том же формате, что и предыдущий проект (`Urok2_LLM`), не разбираясь в нём заново.

**Аудитория нового проекта — руководители и сотрудники малого и среднего бизнеса.** Педагогическая специфика предыдущего проекта сюда не переносится (см. «Что НЕ переносить»).

## С чего начать новому агенту

1. Прочитать `CLAUDE.md` — правила проекта (стек, структура, соглашения, правила контента).
2. Прочитать `SYSTEM_PROMPT.md` — тон оф войс, драматургия страницы, дизайн-система, доступность.
3. Прочитать `reference/PATTERNS.md` — готовые к копированию блоки кода.
4. Верстать от `web/TEMPLATE_stranica.html`, а не с нуля.

Скилл `.claude/skills/vebinar-longrid/` подхватится автоматически: он задаёт порядок «план → согласование → вёрстка → браузер → тест».

## Что НЕ переносить из эталонов

Файлы в `reference/` и `source_material/` пришли из курса для преподавателей. **Копируйте оттуда вёрстку, структуру и код — но не смыслы.**

Под нож при переработке:

- любые примеры про школы, колледжи, вузы, студентов, оценки, расписание, учебные программы;
- сюжеты про 152-ФЗ в образовательном контексте, кейсы Минпросвещения, «цифровая безопасность преподавателя»;
- обращение «коллеги», «в вашей педагогической практике», «на вашем занятии»;
- бренд и футер предыдущего проекта (`iivobrazovanii.club`) — заменить на бренд вебинара, в том числе константу `BRAND` в шаблоне, которая подставляется в имя скачиваемой картинки.

Взамен — примеры из бизнес-практики МСБ: продажи, закупки, склад, найм, поддержка клиентов, документооборот, отчётность, маркетинг.

## Про `source_material/`

Это фактура, а не готовый контент — вся она написана под педагогов и требует переписывания:

- `agentnye_sistemy.html` — страница «от ответа к действию»: агенты, MCP, RAG, мультимодальность;
- `instrumenty_mcp_skills.html` + `..._konspekt.md` — самый близкий к теме материал: инструменты, Skills, MCP;
- `Zanyatie2_Agentnye_sistemy.txt` — исходный текст занятия про агентные системы;
- `Analitika_platformy_dlya_AI-agentov.md` — обзор платформ для сборки агентов.

## Скиллы

Проектный скилл здесь один — `vebinar-longrid`. Из глобальных (`~/.claude/skills/`) для этого проекта уместны:

- `matreshka` — маркетинговые задачи: нейминг вебинара, лендинг, письма, посты;
- `course-financial-model` — если понадобится считать экономику самого вебинара.

Глобальный `programma_DPO` под этот проект **не подходит** — он про образовательные программы повышения квалификации.
